# Code of conduct

Be respectful, constructive and specific. Welcome contributors of all backgrounds and experience levels. Critique work, not people; respect privacy and boundaries.

Harassment, discrimination, threats, sexual harassment, doxxing, and deliberate disruption are unacceptable in project issues, pull requests and other project spaces.

Maintainers may edit or remove contributions, restrict participation, or block accounts in proportion to the behavior. They should explain decisions where doing so does not expose private information, consider context, and disclose conflicts of interest.

Report conduct concerns to repository owner candicehell through a private GitHub contact channel if one is available on their profile; do not post private evidence publicly. If no private contact is available, use GitHub's platform reporting tools. A dedicated project conduct inbox and independent appeal process are not yet established.
